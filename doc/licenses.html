1. Summary

lynxcc is the Lynx Game Development SDK: a complete toolkit for building Atari Lynx games. Its toolchain — the C compiler, macro assembler, linker, librarian and related utilities — is derived from cc65 and forms one component of the SDK. The SDK also ships the runtime and the optional subsystem libraries, and will grow to include additional tools and libraries over time. The whole package is distributed under the cc65 license, a zlib-style permissive license reproduced in section 2.

The cc65-derived components carry the cc65 copyright (Copyright © 1998–2012 Ullrich von Bassewitz and contributors) and keep their existing zlib-style notices. On top of that baseline the SDK applies a per-component licensing pattern to the parts this project has authored: the fork's own new toolchain, runtime, library and tool sources are licensed under the Mozilla Public License 2.0 (section 5); the example games and project templates under the MIT License (section 6); and the documentation under Creative Commons Attribution 4.0 (section 7). Every source file carries an SPDX-License-Identifier tag recording which of these applies, so the per-file scope is machine-checkable. Inherited cc65 files and the bundled third-party headers are not relicensed — they keep their own notices, exactly as the Mozilla Public License's per-file scope intends. The full policy and the exact file mapping live in design/LYNX_LICENSE_POLICY_DESIGN.md.

Where a page on this site (notably this one) reproduces a third party's license verbatim, that quoted text remains under its own terms; the documentation license in section 7 covers each page's own prose, not the licenses it quotes.

Two further notices apply to specific parts and are reproduced in full below: the original Atari 8-bit compiler copyright by John R. Dunning (section 3), which still covers small parts of the C preprocessor and main parser, and the notices for the bundled decompression components (section 4).

This page is the canonical registry for license and copyright notices in the SDK documentation; as new tools and libraries are added, their notices are recorded here. The same notices also appear in the top-level LICENSE file and in the headers of the individual source files they cover; consolidating them here does not remove them from any source file, and the per-file notices remain in place as required by the license.

5. SDK toolchain — Mozilla Public License 2.0

The source files this fork has authored from scratch — the Suzy hardware-math routines, the static joypad read (joy-read.s), the compact bitmap-font modules of the static Lynx graphics text system (gfx-setfont/font5x5/text5x5/textvar/fontvar.s), the <lynx/suzymath.h> header, the lnx cartridge tool, the SDK build orchestration, and the test harness — are licensed under the Mozilla Public License, version 2.0. Each such file carries SPDX-License-Identifier: MPL-2.0 and the standard MPL source-form notice. The MPL is file-scoped: it applies only to the files that carry its notice, so inherited cc65 sources (zlib-style) and bundled third-party sources keep their own notices and are unaffected.

In particular, the static Lynx graphics modules and the ComLynx serial modules were extracted and adapted from Karri Kaksonen's cc65 Lynx drivers (the lynx-160-102-16 TGI driver and the lynx-comlynx serial driver). As derived cc65 work they keep his copyright and an extraction note, and remain under the cc65 package license (root LICENSE) — they are not relicensed under the MPL.

The full, verbatim MPL-2.0 text ships with the distribution as LICENSE-MPL-2.0.txt at the repository root. The per-file source-form notice, reproduced verbatim from the license's Exhibit A, is:
