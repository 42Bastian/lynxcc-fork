Lynx TGI fonts

Glyph comparison of the three static TGI fonts.

Every printable slot (ASCII 32–127), with each of the three static TGI fonts drawn at 3× its native pixels. In the 5×5 and proportional fonts, lower-case a–z are folded onto A–Z (marked = X) and stored only once.

ASCIISystem 8×88×8, 0=fgCompact 5×55×5, fixed pitchProportionalvariable width

White = foreground (the pen colour on hardware), dark = transparent. The 8×8 system font stores 8 rows bottom-row-first (flipped here) with 0 = foreground; the two compact fonts store 5 rows top-first with 1 = foreground. adv is the proportional font’s per-glyph cursor advance (ink width + 1).
