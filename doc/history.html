History & credits

The people behind cc65 and its Atari Lynx support.

lynxcc is a fork of cc65, the 6502 cross-development package, narrowed to the Atari Lynx target. The compiler, assembler, linker, runtime library and the bulk of this documentation are the work of the original cc65 authors and contributors; the Lynx-specific runtime, graphics and music code descend from work first written for cc65's Lynx target. This page records who wrote what, since the original bylines were removed from the individual documents. Licensing terms are unchanged and are collected in the consolidated Licenses and copyright notices page.

2. The cc65 toolchain

Ullrich von Bassewitz created cc65 and wrote the great majority of it: the C compiler, the ca65 macro assembler, the ld65 linker, the ar65 archiver, the co65 object-file converter, the da65 disassembler, the sp65 sprite and bitmap converter, and the standard C library. He is also the original author of most of these manuals, including the function reference, the coding hints and the compiler introduction.

Greg King co-authored and maintained large parts of the toolchain and its documentation over many years, appearing as a byline author on the cc65, ca65, cl65 and da65 manuals, the function reference, the compiler intro and the TGI guide.

The Tiny Graphics Interface manual additionally credits Stefan A. Haubenthal, and the compiler introduction additionally credits CbmNut and Stephan Mühlstrasser.

Two standalone guides have their own authors: the self-modifying-code macro package for ca65 is by Christian Krüger, and the “Using GNU Make with cc65” guide is by Oliver Schmidt.

3. Atari Lynx support

The Atari Lynx target is the foundation this fork is built on. Karri Kaksonen wrote the original Lynx runtime support for cc65, including the hardware-tested Lynx TGI graphics driver from which this fork's text driver is derived, and the ABC-notation music player (first dated 02.02.2019). The Lynx manual was originally bylined to Karri Kaksonen together with Ullrich von Bassewitz.

The ABC music player relies on the _IF/_ELSE/_ENDIF structured-assembly macro package by Bjoern Spruck, which originates from the Chipper tool.

On 26.06.2026 the graphics module's public surface was renamed from the historical tgi_/TGI_ prefix to gfx_/GFX_ ("Lynx graphics"), reflecting that it is no longer the cc65 loadable-driver "Tiny Graphics Interface" but a direct-call static library. The old tgi_ names remain as deprecated, removable aliases via <lynx/tgi.h> so existing programs keep compiling unchanged; see the TGI Deprecation section of the migration guide.

On 02.07.2026 the serial-EEPROM read/write calls were renamed from the historical lynx_ee prefix (operation-then-chip, e.g. lynx_eeread_93c46) to a plain eeprom_ prefix with the chip model first (eeprom_93c46_read), matching the naming of every other subsystem. The old lynx_ee* names remain as deprecated, removable aliases in <lynx/lynx.h> (suppressible with LYNX_NO_EEPROM_COMPAT) so existing programs keep compiling unchanged; see the EEPROM API rename section of the migration guide.
